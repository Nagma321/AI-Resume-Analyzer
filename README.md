# AI Resume Analyzer

This project analyzes resumes using NLP and machine learning techniques.  
It scores resumes, suggests job roles, and provides improvement tips.

## Features
- Resume scoring
- Skill extraction
- Job role recommendation
- Comparison of two resumes

## Tech Stack
- Python
- NLP libraries
- Streamlit
- MySQL

## How to run
1. Install dependencies  
2. Run the Streamlit app
